# Kelvo Enhancer - 24/7 Discord Bot

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/waayz922-hub/kelvo-discord-bot)

بوت متكامل يعمل 24/7 لإدارة رتب واشتراكات سيرفر الديسكورد وربطها مع إضافة **Kelvo Enhancer**.

### الميزات:
- مراقبة لحظية وإعطاء اشتراك 3 شهور تلقائياً.
- عد تنازلي وسحب الرتبة تلقائياً بعد 90 يوماً.
- طرد فوري من الإضافة عند سحب الرتبة أو انتهاء الاشتراك.
- خادم Keep-Alive للعمل 24/7 على Render.com.
